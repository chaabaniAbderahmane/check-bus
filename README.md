# 🚌 VoyagePro - Gestion de Voyages Organisés

Application Streamlit complète pour gérer les voyages organisés en bus avec check-in, placement intelligent, chat privé et programme de fidélité.

## ✨ Fonctionnalités

- **👤 Double Interface**: Admin (organisateur) et Client (voyageur)
- **🎤 Saisie Vocale**: Ajout rapide des voyageurs par reconnaissance vocale
- **🎯 Placement Intelligent**: Algorithme optimisé (familles ensemble, filles/garçons séparés, personnes âgées devant)
- **📱 QR Codes**: Accès rapide pour les clients via scan QR
- **💬 Chat Privé**: Communication directe admin-client
- **✅ Check-in**: Confirmation de présence en temps réel
- **🎁 Fidélité**: 10 voyages = 1 voyage gratuit avec système de points
- **🪑 Visualisation Bus**: Plan interactif du bus
